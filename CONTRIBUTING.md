# Contributing

1. Create a new branch from `main`.
2. Make and test your changes.
3. Do not commit `secrets.yaml`, passwords, tokens or private camera URLs.
4. Update `CHANGELOG.md` for user-visible changes.
5. Open a pull request describing what changed and how it was tested.

Please keep hardware pin assignments unchanged unless the change is clearly
documented, because the current values match the Waveshare panel and MAX98357A
wiring used by this project.
